# 反馈：判断一条信息值不值得给

对应书中「有目的的练习包含反馈」一节。书里的核心句：

> 你必须知道某件事情自己做得对不对，如果不对，你到底怎么错了。……如果没有反馈（要么是你自己给自己提出的，要么是局外人给你提出的），你不可能搞清楚你在哪些方面还需提高，或者你现在离实现你的目标有多远。

## 书里的正反例

**反例**（奥尔举的例子）：音乐学生每天练 1 小时，测试总得 C。导师问「你弹对了多少次」，学生答「一次或两次吧」。书里对这段的评论：他练习时「似乎没有人给他提供任何反馈」，而测试的 C 是「一种迟到的反馈」。

**正例**：史蒂夫每次尝试后都立刻知道对还是错。书里说「最为重要的反馈，也许是他自己给自己提出的」——他记得哪些数字串背错了，知道错在哪几个数字，于是能「适当地转变他的关注焦点」。

## 精度阶梯（本 skill 的操作化分级，书里没有）

书里只区分了「有反馈／没反馈」和「及时／迟到」，没有分级。下面这套 L0–L4 是为了让「反馈」这个词能落地，属于本 skill 的补充：

```text
L0 只说好坏        「不太行」                     → 无信息
L1 指出位置        「第三段有问题」               → 知道去看哪，仍不知道改什么
L2 指出类型        「论据和结论对不上」           → 知道问题类别
L3 指出具体一处    「第三段第二句的论据属于结论二」→ 可直接动手
L4 给出下一步动作  「把这两句调换，再读一遍」      → 可直接进入下一轮
```

自己给自己反馈时，目标是 **L3**。书里对 L4 有一个隐含的警告：学生之所以学不会，部分原因是导师替他指出了问题、他从不自己判断。自己练时先试 L3，卡住再用 L4。

## 反馈依附在产物上

书里没有直接这么写，但整章的推导都是这个结构——富兰克林能对照，是因为他有稿子和原文；史蒂夫能改进，是因为每次尝试有对错结果；马戏学校的学生能优化，是因为他记下了每次对话持续多久。

没有产物，就没有可评判的对象。用户说「我每天读一小时书」时，问：**这一小时结束后，你手里多了什么可以被评判的东西？** 答不出，这条练习要改造，不是加时长。

## 时间维度

书里的关键词是**及时**：测试得 C 之所以被点名批评，是因为它「迟到」。动作类技能必须当场反馈，隔一周才知道结果，学不到东西。

## 自我反馈为什么会失效

你不知道自己漏了什么，因为你每次都是这么做的。三个补丁：

1. **先预测再比对**：先写下「我认为这里会出问题，因为……」，再看结果。预测错的地方就是盲区
2. **固定输入集**：书里的英语学习案例——反复问同一个问题、反复看同一部电影，才有效；换不同的题前后不可比
3. **过程留痕**：只看结果只能复盘结论，留下草稿、报错、你当时的第一个假设才能复盘动作

## 反馈变成噪音的四种情况

- **频率太高**：每一笔都纠正等于没有重点，一轮只给一条
- **同时给多条**：用户会挑最容易改的改，真卡点被跳过
- **只给负面**：书里也提到正面的意义——「有意义的正面反馈是保持动机的关键要素之一」
- **跨度太大**：难度过高时，反馈会落到「你基础不行」这种无用结论上，先退回去拆更细
