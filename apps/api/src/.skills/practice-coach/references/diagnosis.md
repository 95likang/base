# 诊断：目标与拆分的常见失误

对应书中「有目的的练习的四个特点」的前两条：**定义明确的特定目标**、**专注**。

## 书里对「目标」的原话

> 如果音乐学生确定了类似下面这样的练习目标，可能会比他漫无目的的练习要成功得多：「**连续三次，不犯任何错误，以适当的速度弹奏完曲子**。」如果不制订这样一个目标，就没有办法判断练习是不是成功了。

书里还强调目标要能**继续往下拆**：把「差点从 20 降到 5 杆」拆成「增加把球打入平坦球道的次数」，再拆成「纠正总是勾球的毛病」。**关键是接受那个一般目标，并将其转化成一些具体目标。**

## 三种常见错法

| 用户的说法 | 错在哪 | 改成 |
| ---------- | ------ | ---- |
| 我想学好算法 | 「好」无法判定 | 给一道没见过的中等题，45 分钟内写出能通过测试的解法，并说清复杂度 |
| 我想提升表达 | 无产物 | 把一段 800 字的材料压成 200 字，别人读完能复述出三个要点 |
| 我想更自律 | 是状态不是技能 | 说出「自律」要支撑的那个具体动作，再对该动作定判据 |

改写后的句子必须填得进 `在 <条件> 下，独立产出 <成果>，达到 <标准>`。填不进就是还没写完，也就是说「没有办法判断练习是不是成功了」。

## 用户拒绝给目标时

「先学着看」「随便练练」不是目标，是情绪。追问一句：**你希望三个月后能拿出什么给别人看？**

- 能答出具体物件 → 以它反推判据
- 答不出 → 先让他把一次完整流程从头到尾做一遍，做出一个样本再回来诊断

没有样本时给方案，方案一定是空的。

## 拆分自检

书里没有给「几条」这个数字，但给了拆分的目的：「将技能分解成一些组成部分，以便反复地练习」。据此检查：

1. **能单独训练**：只练这一条、其他全不动，够练一轮吗
2. **能单独评分**：这一条的分数会不会被其他条目的表现带偏
3. **有外部标准**：这一条做到什么程度算过关，能不能找到范例对照

任一条不过就是粒度问题：太粗继续拆，太细（一次不到 5 分钟）并回上一层。

**3–7 条是本 skill 的经验建议，书里没有这个数字。**

## 单点的确认方式

书里最有效的方法是先定位「停滞点」：稍微逼自己一下，「但不要逼得太狠，只要使自己稍稍超出正常状态便可以。这通常会帮助你搞清楚自己的『停滞点』在什么地方」。

所以不要替用户选单点。让他在这几条里指一条「现在最常出错」的，然后**当场做一次**：

- 做得出来 → 真正的卡点在它前一步
- 做不出来 → 就是它，本轮就练这个
