# 心理表征：专家与新手的真正差别

书中第 3 章。

## 书里的定义

> 心理表征是一种与我们大脑正在思考的某个物体、某个观点、某些信息或者其他任何事物相对应的**心理结构**，或具体或抽象。

书里举的简单例子：一提到蒙娜丽莎，很多人脑海中就会「看到」那幅油画——那个形象就是心理表征。

## 为什么它是分水岭

书里的核心实验：摆一盘真实棋局 vs 一盘乱摆的棋子，让大师、中等棋手、新手各看 5 分钟再复原。

| 棋盘 | 大师 | 新手 |
| ---- | ---- | ---- |
| 真实棋局 | 记住约 2/3 棋子 | 约 4 个 |
| 随意乱摆 | 只能记住 2–3 个 | 2 个 |

**乱摆时大师和新手一样差。** 结论：大师不是记性好，是能把棋子按「有意义的组块」编码。专家与新手真正不同的，是内部结构，不是记忆容量。

书中引西蒙 1973 年的研究：大师、一级棋手、新手的组块记忆量分别是 7.7 / 5.7 / 5.3；估计大师长时记忆里存了 5 万–10 万个棋局组块。

## 书里的五个用途

第 3 章花了五节讲心理表征能干什么：

- **找出规律**：混乱的信息在你眼里有结构。「杰出人物能够看到『一片森林』，而其他所有人，却只看见『一棵树』」
- **解释信息**：新信息进来，知道该挂到已有结构的哪个位置
- **组织信息**：大量事实，知道哪些是一组、哪个是主线
- **制订计划**：不用试错就能排出步骤和备选方案
- **高效学习**：用表征给自己做反馈——「他们用心理表征为自己做出反馈，以便知道自己有没有准确地把握好作品，以及还需要做些什么」

## 怎么炼（书里唯一认可的方式）

**光想造不出来。** 书里给的路径是「预测 → 比对 → 修正」：

```text
1. 看一段局面／题目／素材
2. 先写下你的判断：下一步该做什么，为什么
3. 看专家／标准答案
4. 差在哪一步？是漏了信息，还是看到了但判断错？
5. 只改那一步，下一题再来
```

书里用的原话是：「我们只有努力去复制杰出人物的成就，失败了就停下来思考为什么会失败，然后再去复制，一旦失败了，再次停下来思考原因，如此一而再再而三地尝试，才能创建有效的心理表征。」

这个方法可以用在任何领域：棋谱、代码 review、交易复盘、写作范文、设计稿、手术录像。

### 加速器：看专家的过程，不只看结果

结果只能告诉你「他做对了」。过程才能告诉你「他看到了什么、忽略了什么、先处理哪一块」。有条件就找带解说、带推导、带草稿的版本。

## 一个自检

书里提到的反向指标：新手和中等水平的演奏者「对这件音乐作品听起来应当是什么样子缺乏好的、清晰的想法」，只能分辨自己是不是弹错了音符，其余缺陷要靠导师指出。

所以自检就一句：**你能不能在动手之前说清「好的成品应该长什么样」？** 说不清，说明这一步还没有表征，只在背规则。书里的对照数据：第一次演奏时，最差的学生每分钟错 11 次且只自行纠正 30%，最好的学生每分钟错 1.4 次且自行纠正 80%。
