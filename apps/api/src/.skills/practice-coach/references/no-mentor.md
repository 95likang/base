# 没有导师怎么办（细节）

对应书中第 6 章「没有导师，怎么办」。核心答案：**三个 F** —— 专注（focus）、反馈（feedback）、纠正（fix it）。书原话：「将技能分解成一些组成部分，以便反复地练习，并且有效地分析、确定你的不足之处，然后想出各种办法来解决它们。」

## 一、书里的模板：富兰克林怎么练写作

他没人教，自己造了三个递进的练习。这是全书的范本，值得照抄结构：

1. **练表达**：挑《观察家》上喜欢的文章，给每个句子写简短的内容提示，放几天忘掉措辞，再按提示重写；写完拿原文对照，「在必要时纠正自己写的版本」
2. **练词汇**：因为写的时候「文思泉涌、信手拈来」做不到，就把文章改写成诗（逼自己找同义词），等忘掉原句后再改回散文
3. **练结构**：把提示线索写在另一些纸上并**故意打乱顺序**，等忘记原文顺序后，自己按最合理的逻辑重排、成文、再与原文对比

第三条最关键：**打乱顺序**这一步逼他思考「为什么作者这样组织」。

书里还有个反例：富兰克林同样热爱下棋，但棋艺毫无进步——因为他「很难接触到大师级的棋手」，没有可研究的棋谱。**没有可对照的高水平样本，重复多少遍都不算练习。**

## 二、书里的完整方法论

书里把它总结成一句：「我们只有努力去复制杰出人物的成就，失败了就停下来思考为什么会失败，然后再去复制……如此一而再再而三地尝试，才能创建有效的心理表征。」

落到操作上：

1. 找 3–5 份公认的优秀成品（书里的例子：棋谱、名画、期刊文章）
2. 遮住答案，自己在同样条件下做一遍
3. 逐处对照，**标出差异的类型**——漏了信息／判断错／顺序错／表达差
4. 重复出现三次以上的差异 = 本阶段唯一的改进点

差异必须分类再统计。不分类只记「差得远」，会得出「我水平不行」这种无用结论。

## 三、书里的其他自建练习案例

- **学英语的学生**：在商场里反复问同一个问题，借「顾客的回答相差无几」来听懂正常语速。换不同的问题就没有这个效果
- **看字幕电影**：同一部片反复看，先遮字幕努力听，多遍后再显示字幕检验
- **马戏团演出指挥**：没有观众可练，就去市中心和下班的人攀谈，**用手表记每次对话持续多久**，并记录哪些方法管用
- **喜剧演员**：泡单口俱乐部试演，拿即时反馈，好笑的留、不好笑的扔

共同点：都是自己设计出一个**能拿到反馈的输入结构**，而不是「一遍遍做同一件事」。书里说得很清楚：「毫无目的地一遍一遍地做同一件事情，并不是好办法。」

## 四、过程记录

书里反复出现的动作是「对比自己的产物和原始作品」。要做到这一点，过程必须留痕：

| 领域 | 留什么 |
| ---- | ------ |
| 写作 | 草稿和每一版的 diff |
| 编程 | 每次报错，以及你当时的第一个假设 |
| 交易 | 盘前写下的条件，盘后核对执行 |
| 表演 / 演讲 | 录像，固定机位，同一个开头 |

## 五、什么时候该去找人

书里的判据是「有没有可研究的样本」，不是「有没有导师」：

- 如果这个领域存在可获取的高水平成品 → 自己对照就够
- 如果找不到成品，或你的错误已成习惯动作、自己完全察觉不到 → 需要外部视角
- 书里对后者的原话：这种弱点「时时刻刻都存在，只是通常情况下不容易察觉」，需要「逼自己一下」或找人看过程
